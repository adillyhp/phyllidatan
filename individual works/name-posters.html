student project

This project required the creation of 2 artworks, combining my name with an imaginary, out-of-the-world job. I focused on visual communication using the typeface itself, with the background as acting as a secondary communication.

HOTDOG BALLOON ARTIST

I chose the typeface "Fredoka" because it is more rounded, hence giving a more playful and fun feeling that suits this job.

PASTA MECHANIC

I chose the typeface "Archivo Black" as it has it has a straighter and more rectangular look, which suits this job.
